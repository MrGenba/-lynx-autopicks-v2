NBA / WNBA parallel pipeline
============================

Separate Supabase bk_* tables and Telegram bots/destinations. No change to baseball
models, notifications, odds parser, calendars or data tables.

Data
----
Initial validated history: NBA 2025/26 and 2026/27, WNBA 2026. SportsDataverse
hoopR-nba-data / wehoop-wnba-data public parquet files derived from ESPN box scores.
Checks: event/team/player IDs, scores, shot arithmetic, player/team sums and minutes
including overtime. Exhibition teams excluded by reviewed registry. Incomplete
boxes remain unavailable for training; missing values never become zero or DNP.

ESPN Core direct reader is implemented and tested against full NBA/WNBA examples.
Production returned HTTP 403 on some requests on Oct 23. Direct capture is disabled.
An authenticated server task downloads the public parquet snapshots hourly instead;
the upstream publication cadence is daily and late source updates are reported.
Do not claim live completeness merely because the collector ran successfully.

No raw optical trajectories or proprietary NBA tracking feed is implied.
Available box fields: minutes, starter/DNP, points, rebounds (off/def), assists,
steals, blocks, turnovers, fouls, FGM/FGA, 3PM/3PA, FTM/FTA.

Advanced and tracking aggregates (added Oct 23)
---------------------------------------------
Public SportsDataverse release assets, independently published from NBA/WNBA stats:
https://github.com/sportsdataverse/sportsdataverse-data/releases/tag/nba_stats_leaguedash
https://github.com/sportsdataverse/sportsdataverse-data/releases/tag/wnba_stats_leaguedash
https://www.nba.com/stats/help/glossary
https://stats.wnba.com/players/advanced/
The VPS could download the current Parquet assets. Direct NBA website access was
denied (403); it is not retried. No paid feeds or extra credentials are involved.

Both leagues: base, advanced, defense, miscellaneous, scoring and usage datasets.
NBA additionally: passing (including potential assists), rebounding opportunities,
possessions/touches, drives, catch-and-shoot, pull-ups, shot efficiency, rim defense,
speed/distance, elbow/post/paint touches. These are season aggregates, not optical
coordinates or player-game tracking. WNBA has no tracking assets in this source;
absence is recorded explicitly, never replaced with zeroes or NBA measurements.

Each dataset preserves provider-native field names/units, season type and per-mode.
The provider's Totals label does not mean every field is a count (MIN in the advanced
table is a per-game value). Consumers must interpret the official field definitions.
Ranks and duplicated identity columns are omitted to limit database growth.
Keep provider player IDs alongside canonical ESPN player IDs. Accept only an
unambiguous published crosswalk with matching name, or exact normalized name plus
team. Current-season NBA boxes fill teams missing from the current crosswalk.
Ambiguous/unmatched identities keep player_id=NULL. Conflicting duplicate source
contexts are quarantined in bk_stat_sources.detail, not merged or overwritten.
Rebound-component discrepancies have explicit quality flags. Game counts and
base total points are compared with the complete imported boxes of the same
season/type. Differences are marked, not resolved by choosing whichever is newer.

Tables: bk_stat_sources, bk_player_stat_versions, bk_player_stat_latest.
View: bk_player_advanced_current (one current source row per player/context/dataset).
The view exposes source_status and latest publication/check times; a consumer must
check these, player_id and quality. Changed observations are appended immutably;
identical content is reused. Service credentials cannot update/delete versions.
Publication time and first observation time are distinct. The provider does not
give an exact game cutoff: data_through stays NULL. New rows cannot be used as
historically available pregame evidence before their observation. All are marked
eligible_for_model=false until a separately tested feature integration is approved.
Snapshots older than 48 hours are marked stale, even if the HTTP fetch succeeds.
This addition does not change probabilities, sealed forecasts or value alerts.

Models
------
Experimental baseline and fixed challenger use basketball possessions, pace,
offensive/defensive efficiency, home advantage and regularization. Props use
weighted per-minute history and minutes uncertainty. Combinations are summed
within each historical game, retaining correlations. Integer lines retain pushes.

Snapshots are sealed before tip-off and never overwritten. Missing recent games
block forecasts for the affected teams. Player rosters must be recent and from
the current season; injuries and confirmed starting fives remain UNVERIFIED.
Published projections are conditional on participation, not recommended stakes.

Research includes every sealed forecast and every recorded market, including
discarded candidates. One initial observation per event/book/market/line/side/model
is retained immutably; bk_quotes is the mutable current price, never test evidence.
Final outcomes settle wins/losses/pushes; DNP is void, missing player data stays pending.

Predeclared primary comparison: first 200 paired prospective games, margin MSE,
fixed-seed paired bootstrap 95% CI. Improvement requires the whole CI below zero.
This is a claim about margin prediction only, not all props or profitability.
No automatic model promotion; a subsequent hypothesis needs a fresh test cohort.
Four OpenAI reviewers audit data, model, market and risk once daily per league.
JSON evidence paths are validated. Numeric probabilities come from the models.
Budget: at most 16 reserved calls/day; ordinary schedule uses 8. Independent key.

Odds
----
VPS/Tor CuotasAhora reader, exact international bet365 only, full game including OT.
Supported: moneyline, total, spread. Event date, home/away order, league and market
scope checked. Aggregated best-book prices are never treated as Bet365 prices.
Each market has its own observed timestamp and 15-minute expiry. The bookmaker's
own update timestamp is unavailable and explicitly recorded as unknown.
CuotasAhora does not supply player props. A separate anonymous, direct VPS reader
uses the public Winamax.fr NBA/WNBA match pages for paired over/under player lines:
points, rebounds, assists, threes, PRA, PR, PA, RA. The source is explicitly FR;
equivalence to Winamax Spain is not verified. No proxy, login or alternate-domain
retry. An explicit access denial stops the collector until operator review.

Exact league, participants, future visible UTC time and player name are checked.
Calendar tolerance is 20 minutes (the observed source difference was 15 minutes),
stored explicitly; expiry uses the earlier start. Only a unique player in that
game's sealed forecast can become a paper candidate. Unmatched quotes are retained
with a null player_id, not silently assigned. List expansion failures mean partial
coverage; unavailable markets and missing projections never become invented odds.

The official rules reference is dated 2024-08-06 and includes overtime for these
markets. The current rules revision is unconfirmed and remains a candidate caveat.
No automated bets are placed. A once-per-game Telegram price summary is sent in
the last 6 hours, with an explicit Winamax.fr source and no claim of proven edge.
WNBA is read when upcoming games enter the 12-hour window; no individual markets
were visible during the initial manual probe. Check state/quotes for live coverage.

PS3838 public reference prices
-----------------------------
Anonymous Chrome on the VPS reads PS3838's public basketball page and opens each
selected game's additional markets. No login or API credentials are required.
Supported: visible full-game moneyline, spread, total, player points, rebounds,
assists, threes and PRA. English/French player market headings are recognized.
The site explicitly labels anonymous prices as delayed; the delay duration and
bookmaker update timestamp are unknown. All stored observations retain delayed=true,
reference_only=true and source=ps3838_public_delayed. They are excluded from EV,
paper candidates, market benchmarks and executable-odds Telegram summaries, even
when their capture timestamp is fresh. Overtime rules remain unverified.
Exact teams, league and date are required (20-minute calendar tolerance, recorded).
Unmatched player names retain a null player_id. Only a unique player in the same
game's sealed forecasts is mapped. No probabilities or decisions are overwritten.
WNBA shares this reader when games enter the 12-hour window; offered markets still
depend on the public site. A source access denial permanently opens its separate
circuit until operator review. Missing listings receive a 30-minute backoff.
The October 23 anonymous NBA probe returned game and player prices for three games.
Oddschecker was also tested directly from the VPS: Cloudflare HTTP 403 before
login or prices. No credentials were used and no automatic reader was enabled.

Operations
----------
Lynx Basketball - capture: hourly at minute 1, POST /basketball-stats/start.
Lynx Basketball - advanced: starts hourly at minute 11, polls at 16/21/26;
POST /basketball-advanced/start. Reuses unchanged release assets. Source updates are
daily (upstream dependent), not live. Completion/error is checked on following ticks;
operational failures use the existing per-league Telegram deduplication mechanism.
Lynx Basketball - odds: every 5 minutes, existing authenticated scrape start/status.
Lynx Basketball - props: every 5 minutes offset 2, separate Winamax.fr jobs/state.
Lynx Basketball - ps3838: every 5 minutes offset 4, delayed references only.
Lynx Basketball - analysis: every 5 minutes offset 3, calculations once per game.
Lynx Basketball - research: daily 09:00 UTC; weekly progress and proven improvement.
Capture, odds and forecasts run in independent server workflows. Shared scraper
semaphore limits browser concurrency. Import runs separately from the main event loop.
Per-job database leases, idempotent Telegram claims and message_id acknowledgements.
Failed sends retry up to 5 attempts; pregame messages expire at tip-off.

Secrets are supplied by private deployment configuration; no env files are committed.
Service-role-only RLS/grants. SQL install: sql/supabase_basketball.sql and
sql/supabase_basketball_advanced.sql.
Builder: basketball/build_workflows.js. Local test:
node --test --test-isolation=none tests/basketball.test.js tests/winamax.test.js tests/ps3838.test.js
node --test --test-isolation=none tests/basketball_advanced.test.js
python -m unittest discover -s tests -p test_basketball_advanced.py
